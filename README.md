# Dev-Folio

A responsive single-page portfolio landing page built for the InternVision
Full Stack Web Development internship (minor project).

## What it includes

- Responsive Bootstrap 5 navbar
- Hero section with a photo placeholder
- Skills section with six Bootstrap cards (hover effects)
- Contact form validated with plain JavaScript
- Footer with copyright and social links

## Tech used

HTML5, CSS3, Bootstrap 5 (CDN), JavaScript (DOM and form validation), Git and GitHub.

## Form validation rules

- Name: cannot be empty
- Email: cannot be empty and must match a simple email pattern
- Message: at least 10 characters

Errors are shown under the field. When all fields are valid, the console
prints "Form submitted successfully!".

## How to run

Open `index.html` in a browser. No build step is needed.
